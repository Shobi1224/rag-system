# KIP-704: Send cluster ID in Fetch and Produce requests

## KIP-704: Send Cluster ID in Fetch and Produce Requests

### Summary
Included cluster ID in client requests to prevent clients from mistakenly reading or writing to the wrong Kafka cluster during DNS failovers.
